# PRD Agent

An AI-powered command-line interface (CLI) tool designed to help developers and product managers generate structured, comprehensive Product Requirement Documents (PRDs) quickly and efficiently.

## 🚀 Features

- **Interactive CLI Interface:** Seamlessly prompt the agent right from your terminal.
- **Structured Requirements:** Automatically organizes user goals into standard PRD sections (Overview, User Stories, Technical Requirements, Out of Scope, etc.).
- **Local Execution:** Run and manage your workflows entirely in your local environment.
